# 下载工具易用性检查 · 2026-11-17

判断标准是首次访问者能知道当前状态、下一步操作、文件保存位置，以及失败后如何继续。自动化检查可以验证功能与提示衔接，不能替代首次用户试用或手机真机验收。

## 结论

Windows 10/11 的主要下载流程已有逐步引导，正常情况下无需输入命令：粘贴分享文字 → 解析 → 文件列表默认全选，可进入目录调整选择 → 按所选文件核对金额 → 前往支付宝 → 返回本站确认 → 打开浏览器下载列表 → 双击 CMD → 查看进度与保存文件夹。

全设备、全环境仍未达到同一程度的易用性。手机普通浏览器不能稳定直接下载，当前建议复制订单号到 Windows 电脑恢复；aria2 需要兼容下载器。Android Chrome 唤起支付宝 App、真实付款后返回以及手机本地下载器仍需要真机实测。

## 检查结果与修正

| 环节 | 检查结果 |
| --- | --- |
| 解析前 | 收费规则置顶，完整分享文字可自动识别提取码；粘贴权限失败有手动粘贴提示。 |
| 服务连接 | 连接失败显示“重新连接服务”，保留分享文字；不会停在无限等待提示。 |
| 金额核对 | 一个文件 ¥0.50，多个文件按所选文件的总大小核价；统计失败有重试按钮，失败不会创建付款订单。 |
| 支付 | 第 02 步直接显示服务器报价及“确认金额 · ¥…”按钮，随后明确前往支付宝；勾选变化即撤销旧报价，创建订单期间锁定选择。只有服务端确认到账才交付。 |
| Windows 下载 | 告知浏览器保存的是任务，Ctrl + J 查找任务、双击运行、查看文字进度与 Downloads- 文件夹；无法确认本地保存时不显示虚假的成功状态。 |
| 下载教学 | 顶部“帮助”、付款前及下载页均可打开六步教学：解析、选择付款、保存查找 CMD、移动位置、双击运行、查看文件；含手机恢复和常见问题。关闭后保留原操作；电脑与手机均可滚动阅读。 |
| 手机下载 | 主要按钮改为复制完整订单号，提供在电脑打开本站、进入“我的订单”、恢复、选文件和运行任务的步骤。aria2 放入其他方式。 |
| 重新下载 | “我的订单”直接提供下载和重新选择；第 03 步也可重新选择已购文件，待支付订单可返回列表调整勾选。跨设备可凭完整订单号恢复，仍按原付款后 24 小时计算。 |
| 失败重试 | 任务生成失败保留选择并提示免费重试；退款及过期订单不交付新任务。 |
| 反馈 | 可携带当前订单号提交错误信息；网络失败保留内容，同次重试沿用提交标识，朋友任务不会误带旧付款订单。 |

## 尚需真机确认

1. Android Chrome 打开支付宝 App，完成一次实际付款，再返回本站自动确认原订单。

3. 如需宣传手机直接下载，先针对明确支持的手机本地下载器完成保存任务、打开、请求设置和续传验证。
