# 音乐页设计记录

## 方向与边界

按用户指定的 Spotify 前端方向重做音乐页，借鉴 BiliTune 的三栏桌面布局、封面卡片、播放详情和固定底栏。模式为 Redesign · Overhaul，仅调整音乐页面；主站导航位置、音乐地址、歌单和既有取流、音质、扫码登录接口保留。

受众是浏览个人网站并收听收藏歌曲的访客。界面作为播放器工作区，适配近距离手机和桌面浏览，不采用介绍产品的落地页结构。视觉温度沉静，实际封面承担色彩；显示真实歌曲和本浏览器的收藏、播放记录，不制造排行榜、推荐数据或歌词。

Design Read：播放器工作区；视觉变化 6、动效 3、信息密度 7、素材依赖 8、品牌保留 6。稳定三栏和歌曲网格支撑信息密度；仅播放状态、悬停按钮和面板切换运动；主站个人身份保留，Spotify 仅作为视觉参考。

## 设计系统

- 底色 `#000000`，面板 `#121212`，抬升表面 `#1f1f1f`，悬停 `#2a2a2a`。
- 文字 `#ffffff` / `#b3b3b3`，强调 `#1ed760` / 悬停 `#3be477`，歌单头部森林绿。
- 字体使用本机 Segoe UI / Microsoft YaHei；中文为主，辅助英文较小。歌单标题 40–76px，正文 14–16px，元信息 11–13px。
- 间距基于 4px：8、12、16、24、32。外框留 8px，面板圆角 8px，封面 4–6px，播放按钮圆形，筛选按钮胶囊形。
- 阴影集中于封面与浮层，面板主要通过底色区分。悬停 160ms，播放均衡器只在实际播放时运动，支持减少动态效果。
- 桌面为资料库 / 内容 / 当前歌曲，窄桌面默认收起当前歌曲栏，手机单栏及底部播放器。主导航使用全站共用几何尺寸。

## 素材与交互

封面来自已发布 B站视频的公开详情，缓存于 `public/music/artwork/`；歌单封面为前四首歌曲封面的拼图，属于真实收藏内容。不存在封面时显示明确的音符占位。图标使用 Lucide 0.468.0 的本地 SVG，授权文本随文件保留，不依赖在线图标 CDN。

资料库展示全部歌曲、我喜欢的、最近播放。后两者只记录当前浏览器的喜好，不向 B站账户写入。歌曲卡片和行内播放入口使用既有播放方法。右侧队列可选择歌曲；随机和循环与播放引擎一致。音质和 MV 继续使用现有功能。

最需保护的是视觉重排后的控制连接：保留音频元素、登录窗口和原有关键控件 ID；扫码登录及凭据处理代码不因设计变更重写。
