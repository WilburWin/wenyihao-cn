# 工具页反馈

工具页底部“问题反馈”和下载、订单弹窗内的“遇到问题？提交反馈”打开私密表单。订单入口可预填本站订单号。支持链接解析、下载、支付、退款申请、功能建议与其他问题；问题描述必填（5–3000 字），联系方式与订单号选填。表单提示不要提交密码、访问码、完整下载任务等凭证。

`POST /api/tools/feedback/submit` 只接受同源 JSON，限制流式请求体至 16KB。反馈不依赖网盘 Agent 在线，也不要求创建订单或付款。保存成功返回随机反馈编号与提交时间，不返回联系方式或描述内容。提交标识用于一天内的重复请求去重，网络超时重试不重复创建；编辑内容会使用新标识。按天哈希的访客地址用于频控，不保存原始 IP；一分钟最多一条，每个访客每天最多十条，全站每天最多五百条。正文按纯文字处理，不执行用户提供的 HTML。

反馈、联系方式及内部备注存入现有 DownloadBridge Durable Object 的独立 `feedback:` 命名空间，仅授权管理员可读，保留 180 天，现有 alarm 清理过期记录。与公开留言板完全分开。订单号属于用户填写信息，管理页明确显示“用户填写”，处理退款时仍需核对原订单与支付宝账单。提交反馈不会改变付款、订单授权或退款状态。

## 管理入口

打开 `/tools/feedback-admin/`。使用专门的 `TOOLS_FEEDBACK_ADMIN_KEY` 登录，密钥最少 32 字符；可直接输入，或选择本机配置 JSON（格式为 `{"key":"实际管理密钥"}`）。管理配置只在本机读取，密钥通过 HTTPS Authorization 请求头发送，不进入 URL、前端源码、浏览器存储或日志。退出与页面关闭会清除页面内存中的密钥及反馈数据。

管理列表每页 25 条，按新到旧显示；可标记“待处理 / 处理中 / 已解决”，填写仅管理员可见的处理备注。状态及备注持久保存。没有自动邮件或聊天通知，人工按用户留下的联系方式回复；未留下联系方式时无法主动回复。

接口均使用 POST 与 `Authorization: Bearer <TOOLS_FEEDBACK_ADMIN_KEY>`：

| 路径 | 内容 | 用途 |
| --- | --- | --- |
| `/api/tools/feedback/admin/list` | `cursor`（可选） | 分页读取私密反馈 |
| `/api/tools/feedback/admin/update` | `id`, `status`, `note` | 保存处理状态及备注 |

本机管理配置保存在 `C:/Users/WYH/.ssh/site_feedback_admin.json`，不要提交 Git、发给访客或复制进网站静态文件。忘记密钥时，生成新的随机密钥并以 Wrangler Secret 配置 `TOOLS_FEEDBACK_ADMIN_KEY`，同时更新本机文件。

测试覆盖私密存储、越权读取和修改、同源校验、正文大小、频控、重复请求、分页与过期、离线网盘服务，以及手机表单、失败保留内容、订单号预填、管理登录、纯文字显示和处理结果保存。
