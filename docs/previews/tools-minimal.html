下载教学

当前是设计预览。文件和订单为示例；“模拟支付”不会扣款，“保存 CMD 任务”不会保存文件。以下为正式使用流程。

先保存 CMD。双击运行，才开始下载。

付费后先获得 CMD 脚本下载工具，网页不会直接下载你勾选的文件。CMD 会替你批量下载，无需逐个点击，也不用输入命令。

本站生成的 CMD 是下载任务脚本，不是病毒，可以放心下载。它调用 Windows 自带工具，无需安装软件或管理员权限。此说明仅指本站生成的任务脚本。

【仅限 Windows 10/11】【不兼容苹果 iOS】

iPhone、iPad、安卓手机和 macOS 不能直接运行此 CMD。手机可以付款，但要有 Windows 电脑才能按本教学下载。

粘贴链接 → 选文件并付款 → 保存 CMD → 移到目标位置 → 双击下载 → 打开文件夹

  1. 粘贴链接，点击“解析链接”

    打开 01 解析链接，把百度网盘链接或整段分享文字粘贴到输入框。提取码会自动识别；没识别出来，就填写分享者提供的提取码。

    点击 “解析链接”。成功后会自动进入文件列表，不会在这一步收费。

    看到文件和文件夹列表，就继续下一步。解析失败时先核对链接、提取码，再重试。

  2. 勾选文件，核对金额，再付款

    在 02 选文件并支付 中，文件默认全部勾选。取消不需要的文件；勾选文件夹，会选中里面的文件。想看文件夹内容，双击文件夹，或点击旁边的 “进入”；看完点“返回上级”。

    检查底部的 已选文件数、总大小、金额，确认无误后点击支付按钮，前往支付宝付款。单文件 ¥0.50；多个文件按勾选总大小收费，具体以页面核对金额为准。

    付款后返回本站，等页面确认到账。仍显示等待付款时，查询付款结果；已扣款不要重复付款，有疑问先反馈。

    复制并保留 DL 开头的本站订单号。它用于换设备恢复下载，不是支付宝交易号，请妥善保管。

    本站确认到账后，进入“03 下载文件”。朋友访问码用户按页面提示下载，无需付款。

  3. 保存 CMD，在浏览器下载列表找到它

    Windows 电脑确认付款后，网页会请求浏览器保存任务。没找到时，在 03 下载文件 点击 “保存 CMD 任务”。

    在浏览器中同时按 Ctrl + J 打开下载列表。找到名称以 Downloads- 开头、后缀为 .cmd 的文件，点击它旁边的文件夹图标或 “在文件夹中显示”。

    任务文件示例：Downloads-20261117-ab12cd34.cmd
    实际名称每次可能不同。若电脑隐藏后缀，可能只显示 Downloads- 开头的名称。

    这时保存的是小型任务文件，所选内容还没有开始下载。浏览器显示任务保存完成，不等于资料下载完成。

  4. 把 CMD 移到你想保存文件的位置

    想存到 D 盘，就先在 D 盘建一个文件夹，例如 D:\我的下载。选中刚才的 CMD，按 Ctrl + X 剪切；打开目标文件夹，再按 Ctrl + V 粘贴。

    不需要换位置，也可以留在原文件夹。开始前确认这个磁盘有足够空间；不要修改 CMD 内容或后缀。

    CMD 放在哪里，下载内容就保存在哪里的 Downloads- 文件夹中。

    D:\我的下载\
├ Downloads-20261117-ab12cd34.cmd   ← 双击这个
└ Downloads-20261117-ab12cd34\      ← 运行后，文件保存在这里
   ├ 第二章.pdf
   └ 课程资料\

    上方是位置示例，不是实际下载结果。要换保存位置，请在开始运行前移动 CMD。

  5. 双击 CMD，开始批量下载

    在目标文件夹里，双击 CMD。出现文字窗口，显示正在下载的文件名、进度和速度，就说明任务开始运行了。

    不用输入命令，不用逐个点文件。保持联网，等待任务自动下载所选内容；可最小化窗口，但不要关闭窗口或让电脑进入睡眠，也不要反复双击启动多个相同任务。

    看到 “全部文件下载完成”，再去查看文件。若窗口显示失败，按下方常见问题处理。

    下载速度由百度与当前网络决定，本站不承诺固定速度。网页不会显示电脑任务的实时进度，以 CMD 文字窗口为准。

  6. 打开 CMD 旁的文件夹，查看下载内容

    回到放 CMD 的位置，打开与它 同名、但没有 .cmd 后缀 的 Downloads- 文件夹。你勾选的文件就在里面，原有子文件夹结构会保留。

    需要重选部分文件时，进入 04 我的订单，找到已付款订单，点击 “重新选择文件”，勾选后重新生成任务。只能选择本订单已购文件，原有效期内不重复收费。

    文件已经下载完成后，会继续保留在电脑上；订单到期不会删除这些文件。

遇到问题，按这里处理

手机已经付款，怎么在电脑下载？

在手机上复制 DL 开头的本站订单号。在 Windows 电脑打开本站 → 04 我的订单 → 粘贴订单号 → “恢复下载” → 勾选文件并生成任务 → 按上方第 3—6 步操作。

必须在原付款后 24 小时内恢复；换设备和重新生成任务都不会延长有效期。iOS 和安卓不能直接运行此 CMD。

付款后怎么只有 CMD，没有资料？

这是正常流程。网页先保存 CMD 下载工具，双击运行后才开始下载资料。请按第 3—6 步找到任务、移到目标位置，再双击运行。

找不到 CMD，或浏览器没有保存？

先按 Ctrl + J 查看下载列表，用“在文件夹中显示”找到它。确实没有时，回 03 下载文件 点 “保存 CMD 任务”；也可从“我的订单”打开有效的已付款订单重新生成。

网页无法确认你的电脑是否已保存成功，以浏览器下载列表和电脑上的实际文件为准。保存被拦截时，请保留提示文字，通过“反馈”联系站长处理。

断网、关了窗口，怎么继续？

网络恢复后，在任务有效期内 重新双击原 CMD。保留原下载文件夹及其中的临时文件，任务会尝试继续未完成的内容，已有完整文件会跳过。

续传时，CMD 和原 Downloads- 文件夹要保持在一起。不要只把 CMD 移到新位置，也不要删除未完成内容。需要重新生成任务时，在原付款后 24 小时内从“我的订单”操作。

运行失败、窗口闪退，或者只下载了一部分？

先确认使用的是 Windows 10/11、网络正常、磁盘空间足够、订单仍有效；可以先重新运行原任务。若提示订单过期或已退款，不能继续获取新下载地址。

仍失败时，保留窗口中的错误代码或提示，到 “反馈” 选择“下载问题”，填写 本站订单号、在哪一步失败、错误文字。需要回复请留联系方式；不要提交密码、访问码或完整 CMD 内容。

部分文件失败时，其余成功的文件仍保留；不要删除整个下载文件夹。

24 小时从什么时候算？重试会再收费吗？

从 原订单付款成功 起算 24 小时。有效期内，为本订单已购文件重新生成任务、恢复下载和重新选择部分文件，不重复收费，也不会重新计时。

超出有效期或订单已退款，不能再生成有效任务或获取新下载地址。已保存到电脑的内容不会因此被删除。

下载完成的文件在哪里？

找到你运行的 CMD，打开它旁边同名的 Downloads- 文件夹。例如 CMD 在 D:\我的下载，内容就在这个位置下的 Downloads- 文件夹里，而不是自动存进浏览器默认下载目录。
