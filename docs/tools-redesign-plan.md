# 下载工具改版设计 · 方向稿 v0

状态：独立交互预览 v5 已制作：[打开预览](previews/tools-minimal.html)。右上角新增朋友入口：[预览朋友入口](previews/tools-minimal.html#friend)，示例访问码为 `friend`，仅在本地切换免费模式。增加深绿与金色，01—04 导航加大加粗，反馈恢复原完整表单与回执流程。下载页明确先保存 CMD，双击运行才开始下载；教学重写为六步操作及折叠常见问题：[直接打开教学](previews/tools-minimal.html#help)。未修改正式页面、样式、脚本或服务，未发布。预览中的文件、订单及付款均为示例；可直接切换四个入口审阅。

## 目标与范围

面向第一次使用的下载用户。用最短的指令完成四个核心入口：

1. 解析链接。
2. 选文件并支付。
3. 下载文件。
4. 我的订单。

第 4 项是可随时进入的订单管理入口，不是下载后的必做步骤。第 1—3 项连续执行；未完成前置步骤时，点击后提示下一步，不展示无法操作的空屏。

改版方式：视觉及页面结构重做，保留现有业务规则。当前正式版保留，方向确认后制作独立可点击预览；预览使用示例数据，不接真实支付或下载，预览确认后再接入正式功能。

## 当前界面的取舍

保留：收费规则显眼、默认全选、双击文件夹、按勾选计价、付款后生成任务、订单恢复与重新选择、下载教学和反馈。

重组：左侧使用方式栏与主视图合并为一个工作区；付款弹窗合并进文件选择页；下载教学改为随需打开；手机单列、纵向阅读。

删除：工具区的宣传句、英文装饰标签、重复下载说明、大块流程介绍和装饰图标。整站其他页面与导航不在此次改版范围内。

保持：接口、金额计算、签名验证、退款权限、原付款后 24 小时有效期、朋友访问码、已购范围、反馈功能、任务生成方式、个人订单记录与站点路由。

最高风险：用户把“下载任务”误认成原文件。处理：第 2 步付款前显示一句 Windows 要求，第 3 步直接展示 CMD 的三个操作及保存位置。

## 视觉系统

自定义方向：操作指令板。强调动词、顺序、当前状态；不使用迷彩、准星、军衔、闪烁光标等装饰。

- 背景：#FFFFFF。
- 正文：#182D25。
- 主色：#204D3D；收费区底色、主按钮、勾选和当前步骤；按钮白字。悬停 #153B2D。
- 收费金额：#F0D48A（金色，深绿底）；付款金额 #805A17（金棕，白底）。
- 分区底色：#F3F7F4；当前步骤 #EAF2EC。
- 分隔线：#D7E1DA；深绿收费区分隔线 #537464。
- 次级文字：#57685F；深绿收费区辅助文字 #D7E6DB。
- 错误：#A12622，仅在出错时使用，同时保留文字说明。
- 字体：中文系统无衬线（Microsoft YaHei / PingFang SC），金额和编号用 Consolas / 等宽系统字体。
- 字号：页标题 32px；区块标题 20px；正文及表单 16px；辅助信息 14px。
- 间距：8px 基数，常用 16 / 24 / 32 / 48px。
- 容器：桌面最大 1040px；手机左右各 20px。
- 边角：0—2px，无阴影、渐变、装饰动画。弹窗仅供帮助、反馈和必要确认。
- 操作：主要按钮至少 48px 高；键盘焦点清晰；状态变化使用文字，不依赖颜色。
- 设计标尺：版式变化 3/10，动效 1/10，信息密度 4/10，图像依赖 1/10，旧视觉沿用 2/10。

每屏用途是发出当前操作指令。主要面向近距离手机和电脑阅读，语气冷静、直接；主内容压到一屏可理解，长文件列表允许滚动。页面只保留一个主要动作，帮助与反馈为次级文字入口。

## 公共框架

收费规则在四个入口上方，保持最高信息优先级。使用一条紧凑价格带，不做五个大卡片。

```text
下载工具                                    帮助  反馈

收费
单文件 ¥0.50  |  多文件按勾选总大小
≤50GB ¥1   ≤500GB ¥2   ≤1TB ¥3   >1TB ¥5
付款后 24 小时有效。有效期内重试不收费。

01 解析链接    02 选文件并支付    03 下载文件    04 我的订单
──────────────────────────────────────────────────────
当前操作
```

价格区的多文件档位按从左至右命中首档理解；展开“计费说明”可查 >50—500GB / >500GB—1TB 的完整区间和十进制容量定义。下单金额始终由后台核对。

手机：价格区改为两行 2×2 档位，单文件价格单列；四个入口按 2×2 排列。正文保持单列，不使用横向滑动步骤条和多栏面板。

## 01 解析链接

```text
解析链接

分享链接
┌────────────────────────────────────────────────────┐
│ 粘贴链接或整段分享文字                              │
│                                                    │
└────────────────────────────────────────────────────┘
提取码  [自动识别，可手填]

                                      [ 解析链接 → ]
```

成功：自动进入 02，全部勾选。

处理中：按钮显示“解析中…”，禁止重复提交，保留输入。

失败：显示“解析失败：提取码错误。修改后重试。”等实际原因，停在当前页面。

朋友入口放在右上角，与帮助、反馈并列。点击弹出访问码输入框，预览仅接受示例 `friend`，不验证正式权限。启用后显示“朋友模式 · 免费使用”，第二入口改为“选择文件”，金额改为“免费”，支付按钮替换为“生成下载任务”。生成后标注“朋友任务”，不展示付费订单号，不模拟创建付款订单。可随时退出朋友模式。正式接入时沿用原有权限验证。

## 02 选文件并支付

```text
选文件并支付
全部文件 / 当前文件夹                         返回上级

☑  名称                                         大小
──────────────────────────────────────────────────────
☑  课程资料 /                       [进入]      2.4GB
☑  第二章.pdf                                   30MB
☑  练习题.zip                                  120MB
──────────────────────────────────────────────────────
全选  清空                        已选 12 个 · 2.55GB

【仅限Windows】【不兼容苹果iOS】当前付费后仅可得CMD脚本下载工具，运行后才开始文件下载，有疑问请看下载教学

本次 ¥1.00                                 [ 支付 ¥1 → ]
```

示例仅说明布局。实际列表与金额由后台读取，不以示例价格替代核价。

文件、文件夹均有复选框。默认全选；目录双击或按 Enter 进入，手机保留“进入”文字按钮。跨目录保留勾选；目录部分选中显示半选。不要把整个目录行点击与勾选、进入混成一个动作。

底部操作区在长列表下保持可见，包含选择统计、Windows 要求、最终金额和唯一支付按钮。手机上下两行，无重叠和悬浮遮挡。

未选文件：显示“未选文件”，支付按钮禁用。

核价中：显示“核价中…”，不显示暂估可付金额。统计失败显示“核价失败。重试。”

支付中：保持本页，显示“等待付款”，提供“前往支付宝”和“查询付款”；不重复建立订单。选择变化后重新核价。

支付确认：自动进入 03；只有服务端确认到账才视为成功。

电脑与手机付款前统一显示红色粗体：“【仅限Windows】【不兼容苹果iOS】当前付费后仅可得CMD脚本下载工具，运行后才开始文件下载，有疑问请看下载教学”。旁边保留可点击的“下载教学”，不能隐藏在帮助中。

## 03 下载文件

桌面正常完成付款后，仍沿用当前自动请求保存任务的行为，不额外增加一道按钮。

```text
下载文件

已付款 · 12 个文件 · 24 小时内可重试
运行 CMD，才开始下载。
网页只保存 CMD 任务文件，不会直接下载所选内容。

1  保存 CMD，按 Ctrl + J 找到。
2  移到目标文件夹。
3  双击 CMD，开始下载。

CMD 所在位置，就是下载保存位置。
内容保存在旁边的 Downloads- 文件夹。

[ 保存 CMD 任务 ]       重新选择文件          下载教学

订单号  DL…                                  [复制]
有效至  实际截止时间
```

网页不声称确认本地任务已保存，也不展示虚构的实际文件下载进度。任务窗口继续显示真实文件名和进度。

用途与安全提示：“本站生成的 CMD 是下载任务脚本，不是病毒，可以放心下载。”“调用 Windows 自带工具下载所选文件。无需安装软件或管理员权限。”安全说明仅指本站生成的任务脚本，不承诺所选文件绝对无毒，不引导关闭系统防护。下载页中与运行提示采用相同的字号、粗体和深绿色。付款前、下载页和教学使用一致说法：运行 CMD 后才开始下载。

手机主操作替换为“复制订单号”，正文为“在 Windows 电脑打开本站 → 我的订单 → 恢复下载”。手机不请求保存 CMD，aria2 留在“其他方式”。

无有效任务时，从此入口返回“先解析链接”或跳到“我的订单”恢复，而不是显示可用下载。

## 04 我的订单

```text
我的订单

订单号  [粘贴 DL 开头的订单号                 ] [恢复下载]
付款后 24 小时内有效。

课程资料                     ¥1.00        已付款
有效至：实际截止时间
[ 下载 ]     重新选择文件                       详情
──────────────────────────────────────────────────────
第二章.pdf                   ¥0.50        待付款
[ 继续付款 ]                                  详情
```

订单按最近创建时间排列。桌面用行、手机用紧凑分组；每条只突出一个可执行主动作。

已付款有效：下载、重新选择文件。

待付款：继续付款、详情中调整文件。

已过期 / 已退款：明确显示状态，不提供有效下载动作；反馈入口保留。

恢复失败时显示具体原因，保留订单号供修改或反馈，不新建付款订单。

空状态：“暂无订单。粘贴订单号恢复，或解析新链接。”

## 帮助与反馈

公共顶部放“朋友入口”“帮助”“反馈”三个文字入口。下载教学重写为单列长文弹窗，在付款前和下载页提供就地入口，不再占大横幅。顶部先说明 Windows 限制、付费后得到 CMD 工具及双击后开始下载，再用六步说明解析、勾选付款、保存并找到 CMD、移动保存位置、双击运行、打开结果目录。每步给出动作和预期结果，含 Ctrl + J、剪切粘贴及目录示例。手机换电脑恢复、中断续传、任务丢失、运行失败、24 小时有效期等问题折叠展示。关闭后回到原操作；预览不扣款、不保存任务、不发送反馈。

反馈沿用原表单的字段与说明：问题类型、选填订单号、选填联系方式、问题描述、隐私与退款说明；提交后保留反馈编号、复制和再写一条。预览仅演示提交结果，不发送请求。正式接入时沿用现有后台、内容保留与重试机制。页面不出现“转存”“导入”，不在生成任务中加入个人品牌字样。

四入口强调：桌面文字 21px、编号 19px，均加粗；手机文字与编号 17px，小屏 15—16px。当前入口采用深绿底、白字、金色编号与底线；未选项保留深色粗体，避免像辅助文字。
