# 当前页面设计

## 内容与导航

首页采用铺满视口的背景图，保留姓名、个人简介和图标形式的账号入口。主要内容放在独立页面，导航依次为 GitHub、B站、游戏、照片墙、音乐、留言板。不要为填满页面制造项目、论文、推荐或统计数据。

各页面的导航尺寸、位置及交互统一；板块使用不同的场景表达内容。中文承担主要信息，英文作为较小的辅助文字。字体优先使用系统字体，避免外部字体请求成为首屏依赖。

## 板块场景

| 板块 | 布局与交互 |
| --- | --- |
| GitHub | 深蓝科技控制台，仓库记录、语言筛选、搜索与状态信息 |
| B站 | 蓝粉色小电视，内嵌个人主页，外部打开入口始终可用 |
| 游戏人生 | 霓虹游戏厅，四台街机入口，落子、翻牌、击球和找猫主题动画 |
| 照片墙 | 暖白墙面、相纸与胶带，分类搜索，大图保留完整画面 |
| 音乐 | 黑灰绿色播放器，桌面三栏与常驻播放条，手机单栏 |
| 留言板 | 浅灰蓝背景、浅木框软木板，图钉便签和独立书写入口 |

游戏页面优先保证操作面积：围棋棋盘居中，找猫网格居中，其余工具靠边；窄屏重排。麻将保留已有布局。全屏布局需同时考虑宽度、动态视口高度、内容溢出与移动端浏览器工具栏，不能只给容器加固定高度。

## 交互与维护约束

- 卡片、导航、播放控件支持键盘操作与可见焦点；装饰素材不进入辅助技术朗读顺序。
- 动画服务于游戏主题和实际播放状态，遵循减少动态效果偏好。
- 空状态与请求失败提供可执行入口，如重试、原站打开或 MV 跳转。
- 视觉调整保留既有路由、控件连接、游戏规则、会话与浏览器存储兼容。
- 照片使用本站缩略图，音乐封面按需在线读取并边缘缓存，浏览页面不触发批量音轨解析。

具体颜色、样式文件和素材来源见 [视觉规范](../brand-spec.md)，播放器布局与控件细节见 [音乐页设计](music-design.md)。
