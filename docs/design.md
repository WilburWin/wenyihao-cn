## 当前范围

首页、游戏大厅、星弈围棋、雀神麻将、黑八台球。卡片直接进入游戏，不增加介绍中间页。网站使用浅灰蓝背景、深灰蓝正文、蓝色链接及系统字体，不依赖境外字体服务；各游戏保留原有视觉和玩法。

## 技术选择

无前端构建框架的静态页面，Cloudflare Worker 托管静态资源和 WebSocket 入口，Durable Objects 以游戏与房间号隔离。放弃旧 D1/HTTP 轮询后端，新增 WebSocket 兼容层，保留经过测试的规则引擎。游戏房主仍计算对局。数据库只保存必要的房间恢复状态，不参与每次消息转发查询。

仅使用 Cloudflare 是明确约束。APAC 提示和持久连接只能优化应用层，不能保证大陆跨境网络时延。公网效果以部署后实测为准。
