        内容实际保存在 CMD 旁以 Downloads- 开头的文件夹中。想存到 D 盘？开始前先把 CMD 移到 D 盘的目标文件夹，再双击运行。

        手机付款后，怎么继续？

        手机不能运行 CMD。请复制本站订单号，在 Windows 电脑打开本站 → “我的订单” → 粘贴订单号 → “恢复下载” → 勾选文件并生成任务。须在原付款后 24 小时内操作，恢复不会延长有效期。

        下载中断、任务找不到或运行失败？

        中断：有效期内重新运行原 CMD 可继续下载；需要重新选文件时，在“我的订单”中点击“重新选择文件”。

        找不到任务：按 Ctrl + J 查看浏览器下载列表，或回下载弹窗重新保存。浏览器是否保存成功，以电脑上的下载列表和文件为准。

        运行失败：保留窗口错误信息，在本站“问题反馈”中提交错误代码和订单号；不要提交完整 CMD 内容。
