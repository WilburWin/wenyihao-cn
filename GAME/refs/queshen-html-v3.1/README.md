# 雀神麻将 · 纯 HTML 前端 v3.1

解压后，单机模式直接打开 `index.html` 可玩。没有构建工具或第三方运行依赖。联机时使用另一个独立压缩包 **雀神联机中继 v1.2**；玩家无需在界面输入中继地址。

## 联机部署

**截图中的现有部署：**本项目 `config.js` 已指向 `https://3plus1.pages.dev`。先把 v1.2 中继部署到截图中的 Pages 项目 `3plus1`，使用现有 D1 绑定变量 `3plus1d1`；再部署此前端，玩家不需要填写中继地址。牌桌顶栏显示到该中继并查询 D1 的 HTTP 往返延迟，每约 8 秒更新一次；对局轮询间隔约 650 毫秒，有事件后约 250 毫秒再次检查，后台页面自动放慢。中继未部署或不可达时显示“中继不可达”。

**同站部署：**也可将前端目录中的 `index.html`、`style.css`、`config.js`、`engine.js`、`sound.js`、`app.js`、`victory.mp3`、`queshen-cover.png`、`queshen-icon.png` 和 `favicon.svg` 复制到中继项目目录，覆盖中继自带的说明页 `index.html`，保留 `_worker.js`，再部署合并目录。若以后更换 Pages 域名，只需修改前端 `config.js`，页面不提供输入框。中继允许跨域请求。

联机时房主创建房间，选择玩法；最多三名好友在首页输入同一个三位房间号加入。房主可在任意人数下点击“开始游戏”，空位自动由电脑玩家补齐。开局后有空位时，后加入的好友也可接管相应座位。房主每次更新牌局时将完整检查点保存到中继 D1；若主动离开，最早仍在线的客人可以接管；若网络突然中断，原房主约 60 秒无心跳后可以接管。接管时原座位变为电脑，其他客人继续接收各自的手牌。无人留在房间时不能接管。

## 操作与界面

- v3.1 统一封面与牌桌的美术风格：深翡翠桌布、木质与暖金桌框、金属风位盘、象牙白牌面、翡翠牌背、珐琅质感筒牌，以及有明暗层次的按钮和座位铭牌。材质由 CSS 与原有 SVG 构成，不增加第三方依赖或网络图片请求。

- 牌河在中心圆盘四周，每行六列，弃牌比先前放大约 50%，靠近风位圆盘。
- 中央风位圆盘只显示东南西北，轮到的方位高亮；副露牌以同款麻将牌沿桌边摆放：自己在右下，右侧玩家在右上，对侧玩家在左上，左侧玩家在左下。已移除左下角出牌记录。
- 左右牌河随行数靠近风位盘，副露牌沿桌面边缘摆放。上方玩法与轮次、行动提示合为一行；操作按钮放大并上移。
- 手牌始终居中，副露牌不会挤偏手牌。默认按花色与点数自动排序；设置中可切换手动理牌，选中后用左右按钮移动，桌面浏览器也可拖动。手动顺序只影响本地显示，刷新后可恢复，同局新摸的牌排在末尾并微微抬起；其他玩家行动时若自己的手牌未变，当前选牌不会被打断；手牌在任何回合均可单击抬起选中，轮到自己时再次点击同一张牌立即打出。点另一张则改选。吃、碰、杠、胡、过按钮在手牌上方。
- 出牌后的吃、碰、杠、胡、过响应不计时，等待有操作可选的玩家确认；响应区显示出牌风位和牌名，最新打出的牌高亮；如需多人响应，会指出尚待响应的风位。空牌墙时不能声明杠；已碰的牌持有第四张时可加杠并补摸。当前行动者姓名牌与自己的出牌区高亮；`Esc` 可取消已选择的牌。玩家离线后由电脑接管其座位。牌桌铺满浏览器可视区域，页面及手牌均无滚动条。
- 万牌用中文数与「萬」，筒牌为圆点图案，条牌为竹节图案，字牌为风与三元牌。
- 首页封面铺满整个背景；页眉和浏览器标签使用透明背景「雀」字麻将牌图标。页眉「⚙」打开牌桌设置，包括音效开关、音量滑杆与自动/手动理牌，设置保存在当前浏览器；打牌与副露时播放本地合成的陶瓷牌落桌声，无需下载音频文件。原有 `favicon.svg` 仍保留备用。
- 条牌使用干净的圆角竹节。胡牌后各家公开的手牌直接显示在各自座位，无中央摊牌窗口。只有胡牌玩家自己听到 `victory.mp3` 并看到彩带与花瓣；其他玩家在桌面中央看到“昵称 胡牌”。音乐在首次操作时预加载并激活 Web Audio；音量滑杆上限为 200%。

## 当前规则覆盖

详见 [GAME_RULES.md](GAME_RULES.md)，该文件逐项写明当前执行的牌组、胡牌、响应优先级、三种玩法差异与未实现规则。

创建房间前可选：

| 玩法 | 已实现的核心规则 | 尚未实现 |
| --- | --- | --- |
| 通用基础麻将 | 136 张，吃碰、暗杠与加杠、点炮、自摸、七对、十三幺 | 国标完整番种及 8 番起和 |
| 广东推倒胡 · 基础 | 136 张，不吃牌，只能自摸，碰与加杠、七对、十三幺 | 买马、完整番数、抢杠胡等地方细节 |
| 四川血战 · 核心 | 108 张无字牌，定缺、不吃、碰与加杠、一家胡后继续，三家胡或流局结束 | 换三张、刮风下雨、查叫、查花猪等结算 |

中国各地麻将没有一套覆盖所有县市玩法的统一规则。本项目尚不支持“中国所有地域规则”，上表只列实际实现的核心流程。选项显示在建房前，房间的玩法由房主创建时固定并同步给客人。进一步实现具体地方规则时，需要该地区的完整规则文本和结算约定。

广东推倒胡的基础行牌差异参考 [JJ 帮助中心规则](https://www.jj.cn/news/320/20111025103000019369.shtml)。各地线下玩法可能与参考版本不同。

## 文件

- `index.html`：页面入口。
- `style.css`：牌桌与移动端布局。
- `config.js`：预设截图中的 `3plus1.pages.dev` 中继地址。
- `engine.js`：规则引擎与电脑玩家。
- `sound.js`：拟真麻将牌碰撞音效与胜利音乐播放。
- `victory.mp3`：胡牌胜利音乐，由用户提供。
- `app.js`：SVG 麻将牌、界面与联机同步。
- `favicon.svg`：图标。
- `queshen-cover.png`：横版游戏封面，1672 × 941 像素。
- `queshen-icon.png`：透明背景游戏图标，1254 × 1254 像素。
- `ASSET_PROMPTS.md`：这两张图片的生成提示词。
- `UX_AUDIT.md`：参考成熟麻将产品的体验检查、已修问题与后续方案。
- `GAME_RULES.md`：当前三种玩法的详细规则与边界。
- `test-v30-rules.mjs`：规则引擎完整对局与关键边界回归测试，运行 `node test-v30-rules.mjs`。

牌局运算仍由当前房主浏览器执行。中继 D1 现在保存完整牌局检查点，包括四家未公开手牌，以便房主离线时恢复；普通客人只收到自己的手牌与公开信息，只有原房主失效后被选中的接管者可获取完整检查点。刷新后可从当前浏览器的本地存储恢复会话。若房主离线前最后一次检查点尚未写入中继，那一次未同步操作可能回退。

## 已验证

三种玩法的牌张守恒与完整牌局；使用真实本地 D1 中继验证 0、1、2、3 名客人开局、电脑补位、定向手牌、四川定缺与状态同步。通用基础麻将和广东推倒胡的单机模式已验证选牌、两次点击出牌和音效设置。另验证自摸与点炮后的座位公开手牌、仅本人可见可听的胜利效果、其他玩家的中央胡牌提示、摸牌微抬、副露四角布局，以及 `victory.mp3` 的两倍增益、实时调节和关闭。v2.7 验证空轮询不重绘牌桌、客人手牌更新时清除旧选牌、Esc 取消选择、行动与最新弃牌提示。v2.8 验证手动理牌切换、重复牌移动、拖动、刷新恢复、摸牌追加、二次点击出正确的牌，以及待响应风位只公开座位状态、其他玩家行动时选牌保持稳定。v2.9 另验证低间隔轮询兼容性、主动离开和超时后的接管、最早座位优先、接管后的定向同步与新玩家加入，以及三种规则的加杠补摸。v3.0 额外验证 36 局完整电脑对局逐步牌张守恒、七对中四张相同作两对、空牌墙不可杠、广东禁吃禁点炮、四川定缺和胡后续打、多人响应优先级，以及离线电脑接手定缺。v3.1 仅调整视觉样式与筒牌矢量图案；手牌选中、理牌、响应和胜利效果的现有回归测试再次通过。尚未对你的正式部署做跨设备试打。
