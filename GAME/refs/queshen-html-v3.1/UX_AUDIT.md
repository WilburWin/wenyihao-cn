# v2.9 体验检查与后续方案

## 对照与取舍

- [SEGA NET Mahjong MJ 操作说明](https://www.sega-mj.com/arcade/howto/play/op/)采用两次触牌出牌，并在可鸣牌或和牌时显示按钮；本项目保留这套明确的二次确认交互。
- [Mahjong 4 Friends 完整文档](https://dev.mahjong4friends.com/pages/faqs/full_documentation.html)描述了玩家座位、风位、轮到玩家的视觉提示、摸牌提示和新手操作说明，也支持单机电脑玩家与多人混合房间。以下改动借鉴了“当前该谁操作”和“当前打出了哪张牌要清楚”的信息安排。
- [SEGA MJ 操作设置](https://www.sega-mj.com/arcade/howto/custom/op.html)提供自动理牌和手动理牌的切换；本项目现已提供默认自动排序和可选的本地手动理牌。

这些资料分别对应日式和多种中式麻将玩法；这里只参考界面交互，不把它们的具体计分规则套用到当前三种规则。

## 本版已修

| 问题 | 复现依据 | v2.7 调整 |
| --- | --- | --- |
| 联机空轮询打断操作 | `poll()` 即使没有事件也执行完整 `render()`，每约 1.3 秒替换整个牌桌 DOM | 空轮询不重绘牌桌；候场名单变化时再刷新 |
| 客人拿到新手牌后旧选牌位置仍在 | `snapshot` 更新手牌时直接保留 `state.selected` | 手牌或局数变化时清除选中；同一手牌的同步保留选择 |
| 响应出牌信息弱 | 吃碰杠胡按钮没有明确说明出牌来源 | 操作条显示“风位打出 牌名”，本次弃牌加亮 |
| 轮次提示不够明显 | 主要靠中心风位盘高亮 | 当前行动玩家名牌及自己出牌区加强高亮 |
| 选牌无法撤回 | 第一次点牌后缺少取消动作 | `Esc` 清除选中；两次触牌出牌仍保持 |

## v2.8 新增

- 默认自动理牌，可在牌桌设置中切换手动。选中牌后可用左右按钮移动，桌面浏览器可拖动；排列保存在本地，联机时只传实际出牌值。
- 新摸的牌接在手动排列末尾并保持轻微抬起；重复牌移动及刷新后显示顺序通过回归测试。
- 出牌需要多人响应时显示尚待响应的风位，不公开其他玩家的牌或具体选择。
- 自己手牌未变化时，电脑或其他玩家行动不会清掉已选中的牌；手牌变化或终局时仍会清除，避免误出。

## v2.9 新增

- 对局轮询从空闲约 1.3 秒缩短到约 650 毫秒，有事件后缩短到约 250 毫秒；候场与后台页面降低频率。仍属 HTTP 轮询，不等于推送。
- 中继 D1 保存房主提交的完整牌局检查点。原房主主动离开或超时后，最早仍在线的客人可经中继校验接管；原座位改由电脑操作，接管者继续保有原座位。测试覆盖主动离开、心跳超时、接管优先级、其他客人的定向快照和接管后新客人加入。
- 三个现有规则核心均增加碰后加杠及补摸；没有补牌可摸时禁止杠。尚未实现抢杠胡与地区计分。

## v3.0 规则审查

- 新增 `GAME_RULES.md`，明确三种已实现玩法的牌组、行牌、胡牌、响应优先级、血战继续及尚未实现的地域规则。
- 修复四川定缺期间真人离线并转为电脑后无法继续；电脑在下一次牌局推进时自动选择缺门。
- 修复空牌墙时弃牌明杠仍会出现在响应菜单；同时修正四川缺门暗杠的按钮提示。
- 七对允许未杠出的四张相同牌计作两对，并拒绝不可能出现的第五张相同牌。
- 将 36 局三规则完整电脑对局的逐步牌张守恒、抢牌优先级、血战续打等回归测试随项目交付。仍需真实设备试打和地区规则逐项扩展。

## v3.1 美术调整

- 牌桌采用与封面一致的翡翠绿、木纹深棕、暖金和象牙白。桌面细纹、框体层次、风位盘、牌背、筒牌、按钮和姓名牌由 CSS/SVG 实现，不额外下载素材。
- 保留原有手牌大小、牌河位置、两次点击出牌和无滚动条布局。小屏风位盘、桌框、铭牌同步缩减；系统偏好减少动态效果时关闭风位呼吸光效。
- 当前环境未安装浏览器可执行文件，尚需在目标桌面和手机浏览器中做视觉检查，特别关注窄屏操作按钮与 14 张手牌的辨识度。

## 下一阶段建议

1. **联机实时性**：本版缩短了轮询间隔并支持接管，但客人操作仍要先到中继、由当前房主浏览器裁决再返回。后续可采用推送及服务端权威状态，减少等待和检查点丢失窗口。
2. **规则与结算**：通用、广东和四川当前只覆盖 README 列出的核心行牌；完整番型、抢杠胡、四川换三张及地区结算需要逐一确认规则文本后实现。不要在选择菜单声称已覆盖所有地域。
3. **触屏手牌体验**：本版已有左右移牌按钮；后续可加入安全的触屏拖动手势，并在小屏设备上继续优化牌面可辨认性。
4. **实际设备验证**：在桌面与手机浏览器上试打，检查窄屏 14 张牌的可辨认性、按钮尺寸、外圈副露和牌河是否遮挡；本版的自动化验证不等于真实浏览器视觉验收。
