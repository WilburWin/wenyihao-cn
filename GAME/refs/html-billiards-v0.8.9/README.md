# HTML Billiards v0.8.9

基于 v0.7.4 重写的 8 球（黑八）网页台球。规则引擎、物理求解器与表现层彻底分离，
浏览器与 Node 测试共用同一份逻辑。

## 运行

直接双击 `index.html` 即可（纯 script 标签，不依赖 ES module、不需要本地服务器，
可放进 iframe / Toy 容器）。

回归测试：

```bash
node test/core.test.js    # 42 项：几何、物理、规则判定
node test/match.test.js   # AI 自对弈、联机状态确定性、规则回归
node test/rolling.test.js # 球面滚动/滑转、旋转、插值、数值稳定性
node test/render.test.js  # 自动/性能/高清 3 档球面投影边界检查
node test/skid.test.js    # 滑行阶段衰减、物理快照精确复现
```

## v0.8.9 更新（黑屏修复与渲染稳定性修复）

- **球体 3D 视觉滚动**：按球实际移动方向、位移和滑转程度累计姿态；数字球的数字和花色条纹有球面透视变化，碰库改变方向后继续自然翻滚，而不是整张二维贴图绕屏幕旋转。
  白球使用训练球常见的红色旋转标记，跟杆、侧旋更容易看清；球面光照固定，不跟着数字一起转。
- **短暂滑行 → 纯滚动**：出杆、球-球和球-库碰撞后会有小幅临时滑动阻力，随后过渡到稳定滚动。
  保留 300Hz 固定物理步进与跨浏览器确定性；新增滑行状态进入联机快照，在双方同版本时保持同步。
- **静态 / 动态双画布**：木框、台呢、库边和袋口仅在加载或画布大小/画质变化时重画；球、球杆、瞄准线和特效独立绘制，固定步长之间通过位置插值改善视觉顺滑程度，避免每一帧重复上传整张桌面图像。
- **计算减负**：库边使用包围盒快速排除远处球，球-球碰撞先用坐标差筛选；花色纹理按自动/性能/高清档设置几何细节。
  自动画质只在运动时根据丢帧和绘制耗时调整，并加入切换冷却，防止频繁改变像素密度；隐藏标签页不累积后台物理帧。
- **测试**：42 项核心回归、30 项整局/AI/联机测试，以及新增滚动与球面绘制测试。设备流畅度仍取决于系统、浏览器和显卡，建议低配电脑使用“性能”画质。

## v0.8.4 更新（开球轮换 / 比分 / 提示文案）

- **开球规则**：单机与联机都是第一局由房主（单机为玩家）开球，之后每局由上一局的赢家开球；
  中途“重新开始”沿用本局开球方且不计分；开球无效时照旧换人开球。换对手或切回单机会开始新的对局，比分清零。
- **比分**：记分牌中间大字为对局比分（赢了几局），下方小字为本局进球数；两侧玩家卡显示“胜 N 局”，
  本局开球方名字旁有金色“开球”标记。比分和开球方随快照同步，主机、客机显示一致。
- **左上角记录**统一为“玩家名 + 事件”：打进几号球、定为全色 / 花色、犯规原因、8 号球结果、谁赢下第几局。
- **桌面下状态栏**改为“玩家名 + 状态”，并修复：
  - 联机时主机把自己视角的“你的回合 / 对方回合”发给客机，客机上显示正好相反；
  - 犯规后的提示立刻被“自由球”覆盖，看不到犯规原因（现在合并为“某某 犯规：原因 · 某某 获得自由球”）；
  - 犯规提示里“球权交给对手 / 你获得自由球”判断反了；
  - 开球提示固定写 P1。
- 结算弹窗显示对局比分和下一局开球方；客机的按钮为“请求下一局”。
- 单机模式的玩家名取联机面板里填写的昵称，没填时显示“玩家”。

## v0.8.3 更新（联机延迟）

- **客机本地预测**：客机松手立刻在本地出杆，同时把“精确初速度 + 出杆前局面指纹”发给主机。
  物理是确定性的，主机用同一组数字重算得到逐位相同的结果，仍以主机为准；指纹不一致时按主机局面重放。
  250ms 往返延迟下实测：客机从松手到球动由约 880ms 降到约 20ms。
- **物理跨浏览器确定性**：物理步进只使用 IEEE-754 保证逐位一致的运算（四则运算与 `Math.sqrt`），
  去掉了 `Math.hypot / Math.exp`；联机快照不再四舍五入；`restore()` 同时恢复球的数组顺序
  （旧版恢复后顺序不同，碰撞求解顺序随之不同，同一杆在两端会滚出不同结局）。
- **自由球 / 叫袋也本地先生效**，不再等一个来回才能出杆。
- **主机请求队列**：主机还在模拟上一杆时收到客机的下一杆，先排队，结算后按顺序处理，不再丢弃。
- **有序合并发送**：同一时刻只有一个发送请求在路上，保证先摆球后出杆；积压的消息合并成一次请求（后端 2.1）。
- **不再半路瞬移**：客机本地这一杆还在滚时收到主机的终局，会等本地结算后再对齐。
- 轮到对方时 150ms 快速轮询，自己瞄准时放慢；画质标签旁显示实时网络延迟。

## 相对 v0.7.4 的主要变更

**规则**

- 开球后台面保持开放（open table），首杆进球不再立即定组；可用开关切换。
- 修复「最后一颗组球与 8 号同杆落袋判胜」的致命 bug，现判负。
- 新增叫袋（call shot）：打 8 号必须指定袋口，可关闭。
- 开球进 8 默认重新摆放 8 号而非判负；开球犯规按 WPA 走重摆。
- 四库开球判定只统计**目标球**碰库，白球不计。
- 开球不再硬编码「必须先碰 1 号」，改为「必须先碰最前排球」。
- 开球犯规限制在开球区（kitchen）内自由球。
- 球跳出台面判跳球犯规并重新置球，不再当作进袋。
- 开放球局同杆进两组时按「先落袋者」定组。

**几何与物理**

- 袋口改为带袋角（jaw）的真实结构，扫掠式落袋判定，可涮袋、贴库球不再必掉。
- 球半径与台面比例修正为 \(R/W \approx 1/45.8\)，接近真实 \(57.15\,\text{mm}\) 球与 9 尺台的比例。
- 随机摆球（8 号固定第三排中心、底排两角异组），球堆紧密贴合。
- 杆法冲量改为与击球力度成正比，侧塞方向修正。
- 力度曲线下限降低，可打轻防守；抬杆门限提高，避免误触出杆。
- 只在必要时做分离修正，消除球堆抖动。
- 固定步长 \(\Delta t = 1/300\ \text{s}\)，单步位移小于球径，不再穿透。

**AI**

- 切角可行性校验（白球路径、目标球路径、切角上限），空杆率从 7% 降到 1.6%。
- 难度由噪声 / 视野 / 走位权重控制，不再靠裁剪袋口列表。
- 新增开球策略、吃袋解球、安全球；会用杆法走位。
- AI 瞄准线可见。

**联机**

- 改为主机权威：客机发请求，主机裁决后广播结果 + 快照硬同步。
- 校验回合归属与自由球权。
- 状态文案改为 `{code, data}` 本地渲染，不再出现「双方都显示轮到你了」。
- 清理全部死代码（`buildInviteUrl` 等）。

**性能与交互**

- HUD 增量更新，蓄力时不再重建 DOM。
- 画布按 devicePixelRatio 渲染，等比缩放。
- 首次交互解锁音频。
- 自由球实时预览合法性，非法位置高亮提示。
- 键盘微调瞄准、取消蓄力、单步击球日志。
